# Глоссарий

## Идея простыми словами

В каждой области свой жаргон. Здесь каждое слово Wavu объяснено одной
простой строкой, с картинкой ресторана там, где она помогает.

![Аналогия с рестораном: Fiji — официант, воркер — кухня, у каждого рецепта своя кухонная утварь](../assets/img/restaurant.svg){ width="560" }

## Слова

**Fiji**
:   Программа для анализа изображений, которой вы уже пользуетесь (ImageJ с
    плагинами). В Wavu это *официант*: диалог на входе, результаты на выходе.

**Wavu**
:   По-фиджийски «мост». Пункты меню в Fiji плюс небольшой помощник на
    Python, которые соединяют Fiji с вашим Python-скриптом.

**Скрипт (script)**
:   Файл `.py` с `PARAMS` и функцией `run`. *Рецепт*.

**Папка скрипта (script folder)**
:   Папка с `pixi.toml` и одним или несколькими скриптами. Её вы выбираете в
    **Run Python Script**.

**PARAMS**
:   Список в начале скрипта, описывающий поля диалога. *Меню*.

**`run(ctx, inputs, params)`**
:   Функция, которую вызывает Wavu. В `inputs` лежат изображения, в
    `params` — остальные настройки, а `ctx` — связь с Fiji.

**ctx**
:   Сокращение от «context» (контекст): `ctx.log`, `ctx.progress`,
    `ctx.cancelled` и компания.

**Воркер (worker)**
:   Небольшая программа на Python на *вашем* компьютере, которая выполняет
    скрипт по запросу Fiji. *Кухня*. Она общается с Fiji только внутри
    вашего компьютера.

**Окружение (environment)**
:   Отдельная папка с одним конкретным Python и пакетами, нужными одному
    скрипту; хранится в `.pixi` внутри папки скрипта. *Кухонная утварь*
    рецепта: его собственные кастрюли, ножи и печи.

**pixi**
:   Бесплатный инструмент, который собирает окружения и скачивает пакеты,
    современная альтернатива conda. Wavu скачивает его за вас.

**`pixi.toml`**
:   *Список кухонной утвари*: какие пакеты нужны скрипту.

**Lock-файл (`pixi.lock`)**
:   *Чек* на кухонную утварь: точная версия каждого пакета. Если
    поделиться им, у всех будет одинаковое окружение.

**conda-forge / PyPI**
:   Два больших онлайн-«магазина» пакетов Python. pixi по умолчанию берёт
    пакеты с conda-forge; PyPI — магазин, где закупается `pip`.

**Массив NumPy**
:   Сетка чисел в Python; так ваш скрипт получает и возвращает изображения.

**Метки (изображение меток, label image)**
:   Изображение, где у каждого объекта своё целое число (1, 2, 3 …), а фон
    равен 0. Fiji показывает его случайными яркими цветами.

**ROI**
:   «Region of interest», область интереса: контур, нарисованный на
    изображении. Fiji хранит их в **ROI Manager**; *RoiSet* — это zip-файл,
    полный таких контуров.

**Кооперативная отмена**
:   Esc поднимает флажок; ваш скрипт проверяет его и сам останавливается.

**Точка останова (breakpoint)**
:   Красная точка в VS Code, на которой работающий скрипт встаёт на паузу,
    чтобы можно было заглянуть внутрь.

**Тег / релиз (tag / release)**
:   Метка версии вроде `v1.0.0` на вашем коде и страница загрузки, которую
    GitHub для неё создаёт.

**CI**
:   «Continuous integration», непрерывная интеграция: робот GitHub, который
    тестирует и упаковывает код, когда вы отправляете тег. По желанию.

**Сайт обновлений (update site)**
:   Источник загрузок для Fiji, который отмечают в **Help › Update…**, чтобы
    устанавливать и обновлять плагины.

## Одним предложением

Fiji — официант, воркер — кухня, ваш скрипт — рецепт, ваши изображения —
ингредиенты, его pixi-окружение — кухонная утварь, а `pixi.lock` — чек.
