# 用語集

## やさしく言うと

どの分野にも専門用語があります。ここでは Wavu の言葉を 1 つずつ、やさしい
1 行で説明します。役に立つところではレストランのたとえも添えます。

![レストランのたとえ：Fiji はウェイター、ワーカーは厨房、レシピごとに専用の調理器具がある](../assets/img/restaurant.svg){ width="560" }

## 言葉

**Fiji**
:   すでに使っている画像解析プログラム（プラグイン入りの ImageJ）。Wavu では
    *ウェイター* です。ダイアログを受け取り、結果を届けます。

**Wavu**
:   フィジー語で「橋」。Fiji のメニュー項目と小さな Python の補助プログラムで、
    Fiji とあなたの Python スクリプトをつなぎます。

**スクリプト（Script）**
:   `PARAMS` と `run` 関数を持つ `.py` ファイル。*レシピ* です。

**スクリプトフォルダー（Script folder）**
:   `pixi.toml` と 1 つ以上のスクリプトが入ったフォルダー。
    **Run Python Script** で選ぶものです。

**PARAMS**
:   スクリプトの先頭にある、ダイアログの入力欄を説明するリスト。
    *メニュー表* です。

**`run(ctx, inputs, params)`**
:   Wavu が呼ぶ関数。`inputs` には画像が、`params` にはその他の設定が入り、
    `ctx` は Fiji への連絡線です。

**ctx**
:   「context（コンテキスト）」の略。`ctx.log`、`ctx.progress`、
    `ctx.cancelled` などの仲間です。

**ワーカー（Worker）**
:   Fiji に頼まれたときにスクリプトを動かす、*あなたの* コンピューター上の
    小さな Python プログラム。*厨房* です。Fiji とは自分のマシンの中だけで
    やりとりします。

**環境（Environment）**
:   1 つの決まった Python と、1 つのスクリプトに必要なパッケージを入れた専用の
    フォルダー。スクリプトフォルダーの中の `.pixi` に置かれます。レシピの
    *調理器具*、つまり専用の鍋や包丁やオーブンです。

**pixi**
:   環境を作り、パッケージをダウンロードする無料のツール。conda の現代的な
    代わりです。Wavu が取ってきてくれます。

**`pixi.toml`**
:   *調理器具のリスト*。スクリプトに必要なパッケージを書きます。

**ロックファイル（`pixi.lock`）**
:   調理器具の *レシート*。すべてのパッケージの正確なバージョン。これを共有すると、
    全員が同じ環境を手に入れます。

**conda-forge / PyPI**
:   Python パッケージの 2 つの大きなオンラインの「お店」。pixi は既定で
    conda-forge を使います。PyPI は `pip` が買い物をする場所です。

**NumPy 配列（NumPy array）**
:   Python の数の格子。スクリプトはこれで画像を受け取り、返します。

**ラベル（ラベル画像）**
:   物体ごとに自分の整数（1、2、3 …）を持ち、背景が 0 の画像。Fiji は
    ランダムな明るい色で表示します。

**ROI**
:   「Region of interest（関心領域）」。画像の上に描いた輪郭です。Fiji は
    **ROI Manager** で管理します。*RoiSet* は、それがたくさん入った zip
    ファイルです。

**協調的キャンセル（Cooperative cancel）**
:   Esc は旗を揚げるだけ。スクリプトがそれを確認して、自分で止まります。

**ブレークポイント（Breakpoint）**
:   VS Code の赤い点。動いているスクリプトがそこで一時停止し、中をのぞけます。

**タグ / リリース（Tag / release）**
:   `v1.0.0` のような、コードに付けるバージョンのラベルと、それに合わせて
    GitHub が作るダウンロードページ。

**CI**
:   「Continuous integration（継続的インテグレーション）」。タグを push すると
    コードをテストしてパッケージにする GitHub のロボット。任意です。

**アップデートサイト（Update site）**
:   **Help › Update…** でチェックを入れて、プラグインのインストールや更新に
    使う Fiji のダウンロード元。

## ひとことで言うと

Fiji はウェイター、ワーカーは厨房、スクリプトはレシピ、画像は食材、
その pixi 環境は調理器具、そして `pixi.lock` はレシートです。
