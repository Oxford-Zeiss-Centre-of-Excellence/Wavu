# Wavu란 무엇인가요?

## 쉬운 말로 설명하면

여러분은 이미 두 세계를 알고 있어요. **Fiji**에서는 이미지를 열고, 영역을
그리고, 측정해요. **Jupyter 노트북**에서는 Cellpose나 scikit-image 같은
Python 도구를 실행해요. 둘 사이를 오가려면 보통 파일을 저장하고, 프로그램을
바꾸고, 다시 불러와야 해요.

Wavu는 그 둘 사이의 **다리**예요. 작업은 Fiji에서 계속하고, Python이
필요하면 메뉴 항목을 고르고, 작은 대화상자를 채우고, OK를 누르면 돼요.
Python 코드가 실행되고, 결과는 새 이미지, 표, 윤곽선으로 Fiji에 돌아와요.

![레스토랑 비유: Fiji는 웨이터, 워커는 주방, 레시피마다 자기만의 식료품 창고가 있어요](../assets/img/restaurant.svg){ width="720" }

레스토랑 그림이 도움이 돼요.

| 레스토랑에서 | Wavu에서 | 실제로는 |
|---|---|---|
| 웨이터가 주문을 받아요 | **Fiji**가 대화상자를 보여 줘요 | Fiji 안의 Wavu 메뉴 항목 |
| 메뉴판 | **PARAMS** | Python 스크립트 맨 위의 짧은 목록 |
| 주방 | **워커(worker)** | *여러분의* 컴퓨터에서 도는 작은 Python 프로그램 |
| 레시피 | **나의 스크립트** | `run` 함수가 있는 `.py` 파일 |
| 레시피마다 있는 식료품 창고 | **환경(environment)** | 그 스크립트에 필요한 패키지만 정확히 담은 폴더 |

레시피마다 자기 창고가 있으니, 한 스크립트에 PyTorch를 설치해도 다른
스크립트가 망가질 일이 없어요. 창고를 함께 쓰지 않으니 아무것도 상하지 않아요.

## 누구를 위한 것인가요?

- 노트북을 쓰고, Cellpose나 scikit-image를 돌려 본 적이 있는 분.
- Fiji를 알고, Python 단계를 그 안에서 *클릭 한 번*으로 하고 싶은 분.
- Java, conda 요령, Docker는 배우고 싶지 **않은** 분.

## 이런 것은 아니에요

!!! warning "빅데이터용이 아니에요"
    Wavu는 이미지를 한 번에 한 장씩 보내고, 그 이미지는 컴퓨터 메모리에
    들어가야 해요(대략 1–2 GB까지). 아주 큰 볼륨, 많은 파일, 전체 슬라이드
    이미지는 배치(batch)나 HPC 워크플로를 쓰세요.

!!! warning "보안 샌드박스가 아니에요"
    환경을 나누는 것은 *패키지*를 떼어 놓을 뿐, 스크립트를 가두지는
    않아요. 스크립트는 여러분의 사용자 계정이 할 수 있는 일은 뭐든 할 수
    있으니, 노트북과 똑같이 믿을 수 있는 스크립트만 실행하세요.

Wavu가 노트북을 대신하지도 않아요. 노트북은 탐색에 좋아요. Wavu는 레시피가
완성되어 Fiji에서 직접 쓰거나 동료가 쓰게 하고 싶을 때를 위한 거예요.

## 실행은 이런 느낌이에요

1. Fiji에서 이미지를 열어요.
2. **Plugins › Wavu › Run Python Script**(Python 스크립트 실행)를 고르고
   스크립트 폴더를 선택해요.
3. 대화상자가 나타나요. 채우고 **OK**를 눌러요.
4. Fiji의 **Log** 창에 메시지가 올라오고 진행 표시줄이 움직여요.
5. 결과가 Fiji에서 열려요.

스크립트를 맨 처음 실행할 때는 느려요. 창고(환경)를 채우는 중이라서
패키지를 한 번 내려받거든요. 그다음부터는 빨리 시작해요.

## 한 문장으로

Wavu는 Fiji가 이미지와 몇 가지 설정을 Python 스크립트에 보내게 해 주고,
스크립트는 자기만의 깔끔한 환경에서 실행되어 결과를 바로 돌려줘요.
