# Wavu 是什么？

## 用大白话说

你已经熟悉两个世界。在 **Fiji** 里，你打开图像、画选区、做测量。在
**Jupyter 笔记本**（notebook）里，你运行 Cellpose 或 scikit-image 这类
Python 工具。要在两者之间来回切换，通常得保存文件、切换程序、再重新加载。

Wavu 就是连接两者的一座**桥**。你继续在 Fiji 里工作；需要 Python 时，
点一个菜单项、填一个小对话框、按 OK。Python 代码开始运行，结果以新的图像、
表格或轮廓回到 Fiji。

![餐厅比喻：Fiji 是服务员，worker 是厨房，每道食谱都有自己的食材柜](../assets/img/restaurant.svg){ width="720" }

拿餐厅来打比方会更好理解：

| 在餐厅里 | 在 Wavu 里 | 实际上是什么 |
|---|---|---|
| 服务员帮你点菜 | **Fiji** 弹出对话框 | Fiji 里的 Wavu 菜单项 |
| 菜单 | **PARAMS** | Python 脚本顶部的一小段列表 |
| 厨房 | **worker** | 在*你自己的*电脑上运行的小型 Python 程序 |
| 一道食谱 | **你的脚本** | 一个包含 `run` 函数的 `.py` 文件 |
| 每道食谱专用的食材柜 | **环境** | 一个文件夹，正好装着该脚本需要的包 |

因为每道食谱都有自己的食材柜，给某个脚本安装 PyTorch，绝不会弄坏另一个
脚本。谁也不跟谁共用食材柜，所以什么都不会坏。

## 适合谁用

- 你会写笔记本，也用过 Cellpose 或 scikit-image。
- 你熟悉 Fiji，希望在那里*点一下*就完成 Python 这一步。
- 你**不**想学 Java、conda 的各种技巧或 Docker。

## 它不是什么

!!! warning "不适合大数据"
    Wavu 一次只传一张图像，而且它必须能放进电脑内存（大约 1–2 GB 以内）。
    对于超大的三维数据、大量文件或全切片图像，请改用批处理或 HPC（高性能
    计算）流程。

!!! warning "不是安全沙箱"
    各自独立的环境只是把*包*分开，并不会把脚本关起来。脚本能做你的用户账号
    能做的任何事，所以只运行你信任的脚本，就像对待笔记本一样。

Wavu 也不会取代你的笔记本。笔记本很适合探索；Wavu 则用在食谱已经跑通、
你想在 Fiji 里使用它（或让同事使用）的时候。

## 运行起来是什么感觉

1. 在 Fiji 里打开一张图像。
2. 选择 **Plugins › Wavu › Run Python Script**（运行 Python 脚本），再选一个
   脚本文件夹。
3. 弹出一个对话框。填好后按 **OK**。
4. 消息在 Fiji 的 **Log** 窗口里滚动，进度条也随之前进。
5. 结果在 Fiji 中打开。

脚本第一次运行会比较慢，因为正在备齐它的食材柜（环境）：包只需下载一次。
之后启动就很快了。

## 一句话总结

Wavu 让 Fiji 把一张图像和几个设置交给你的 Python 脚本，脚本在自己干净的
环境中运行，再把结果直接送回来。
