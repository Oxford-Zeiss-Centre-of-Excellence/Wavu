# Wavu とは？

## やさしく言うと

あなたはすでに 2 つの世界を知っています。**Fiji** では画像を開き、領域を
描き、計測します。**Jupyter ノートブック** では Cellpose や scikit-image
などの Python ツールを動かします。その間を行き来するには、たいていファイルを
保存し、プログラムを切り替え、また読み込む必要があります。

Wavu はこの 2 つの間に架かる **橋** です。作業は Fiji のまま続けます。
Python が必要になったら、メニュー項目を選び、小さなダイアログに入力して
OK を押します。Python のコードが動き、結果は新しい画像、表、輪郭として
Fiji に戻ってきます。

![レストランのたとえ：Fiji はウェイター、ワーカーは厨房、レシピごとに専用の食材庫がある](../assets/img/restaurant.svg){ width="720" }

レストランにたとえると分かりやすくなります。

| レストランでは | Wavu では | 実際には |
|---|---|---|
| ウェイターが注文を取る | **Fiji** がダイアログを表示する | Fiji の中の Wavu メニュー項目 |
| メニュー表 | **PARAMS** | Python スクリプトの先頭にある短いリスト |
| 厨房 | **ワーカー** | *あなたの* コンピューターで動く小さな Python プログラム |
| レシピ | **あなたのスクリプト** | `run` 関数を持つ `.py` ファイル |
| レシピごとの食材庫 | **環境** | そのスクリプトに必要なパッケージだけが入ったフォルダー |

レシピごとに食材庫が分かれているので、あるスクリプトのために PyTorch を
インストールしても、別のスクリプトが壊れることはありません。誰も食材庫を
共有しないので、何も傷みません。

## 誰のためのもの？

- ノートブックを書き、Cellpose や scikit-image を使ったことがある方。
- Fiji を知っていて、Python の処理を Fiji で *ワンクリック* にしたい方。
- Java や conda の小技、Docker を覚えたく **ない** 方。

## できないこと

!!! warning "大きなデータ向けではありません"
    Wavu は画像を 1 枚ずつ送り、その画像はコンピューターのメモリに収まる
    必要があります（だいたい 1〜2 GB まで）。巨大なボリューム、大量の
    ファイル、ホールスライド画像には、バッチ処理や HPC のワークフローを
    使ってください。

!!! warning "セキュリティのサンドボックスではありません"
    環境が分かれているのは *パッケージ* を分けるためです。スクリプトを
    閉じ込めるものではありません。スクリプトはあなたのユーザーアカウントで
    できることを何でもできるので、ノートブックと同じように、信頼できる
    スクリプトだけを実行してください。

Wavu はノートブックの代わりでもありません。探索にはノートブックが最適です。
Wavu は、レシピが完成して、それを Fiji から自分で使いたいとき、あるいは
同僚に使ってもらいたいときのためのものです。

## 実行するとどんな感じ？

1. Fiji で画像を開きます。
2. **Plugins › Wavu › Run Python Script**（Python スクリプトを実行）を選び、
   スクリプトフォルダーを選びます。
3. ダイアログが出ます。入力して **OK** を押します。
4. Fiji の **Log** ウィンドウにメッセージが流れ、プログレスバーが進みます。
5. 結果が Fiji で開きます。

スクリプトの一番最初の実行は時間がかかります。食材庫（環境）に材料を
そろえている、つまりパッケージを一度だけダウンロードしているからです。
その後はすぐに起動します。

## ひとことで言うと

Wavu を使うと、Fiji は画像といくつかの設定を Python スクリプトに送れます。
スクリプトは自分専用の整った環境で動き、結果をそのまま Fiji に返します。
