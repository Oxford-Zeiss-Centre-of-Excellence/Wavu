# Wavu 是什麼？

## 用白話說

你已經熟悉兩個世界。在 **Fiji** 裡，你開啟影像、圈選區域、做測量。在
**Jupyter 筆記本**（notebook）裡，你執行 Cellpose 或 scikit-image 這類
Python 工具。要在兩者之間來回，通常得存檔、切換程式、再重新載入。

Wavu 就是兩者之間的一座**橋**。你繼續在 Fiji 裡工作；需要 Python 時，
選一個選單項目、填一個小對話框、按下 OK。Python 程式碼開始執行，結果會
以新的影像、表格或輪廓回到 Fiji。

![餐廳比喻：Fiji 是服務生，worker 是廚房，每道食譜都有自己的食材櫃](../assets/img/restaurant.svg){ width="720" }

用餐廳來想會比較好懂：

| 在餐廳裡 | 在 Wavu 裡 | 實際上是什麼 |
|---|---|---|
| 服務生幫你點餐 | **Fiji** 顯示對話框 | Fiji 裡的 Wavu 選單項目 |
| 菜單 | **PARAMS** | Python 腳本最上面的一小段清單 |
| 廚房 | **worker** | 在*你自己的*電腦上執行的小型 Python 程式 |
| 一道食譜 | **你的腳本** | 一個含有 `run` 函式的 `.py` 檔案 |
| 每道食譜專用的食材櫃 | **環境** | 一個資料夾，剛好裝著該腳本需要的套件 |

因為每道食譜都有自己的食材櫃，替某個腳本安裝 PyTorch，永遠不會弄壞另一個
腳本。沒有人共用食材櫃，所以什麼都不會壞掉。

## 適合誰用

- 你會寫筆記本，也用過 Cellpose 或 scikit-image。
- 你熟悉 Fiji，希望在那裡*按一下*就完成 Python 步驟。
- 你**不**想學 Java、conda 的各種技巧或 Docker。

## 它不是什麼

!!! warning "不適合大型資料"
    Wavu 一次只傳一張影像，而且它必須放得進電腦的記憶體（大約 1–2 GB 以內）。
    遇到超大的體積資料、大量檔案或全玻片影像，請改用批次處理或 HPC（高效能
    運算）流程。

!!! warning "不是安全沙箱"
    各自獨立的環境只是把*套件*分開，並不會把腳本關起來。腳本能做你的使用者
    帳號能做的任何事，所以只執行你信任的腳本，就像對待筆記本一樣。

Wavu 也不會取代你的筆記本。筆記本很適合探索；Wavu 則是在食譜已經可行、
你想從 Fiji 使用它（或讓同事使用）的時候派上用場。

## 執行起來是什麼感覺

1. 在 Fiji 裡開啟一張影像。
2. 選擇 **Plugins › Wavu › Run Python Script**（執行 Python 腳本），再挑一個
   腳本資料夾。
3. 出現一個對話框。填好後按 **OK**。
4. 訊息在 Fiji 的 **Log** 視窗中捲動，進度條也跟著前進。
5. 結果在 Fiji 中開啟。

腳本的第一次執行會很慢，因為正在補齊它的食材櫃（環境）：套件只需下載一次。
之後就能很快啟動。

## 一句話總結

Wavu 讓 Fiji 把一張影像和幾個設定交給你的 Python 腳本，腳本在自己整潔的
環境中執行，再把結果直接送回來。
